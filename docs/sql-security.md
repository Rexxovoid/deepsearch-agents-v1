# SQL 查询安全与超时重试

## 配置和生效

更新依赖后重启后端：

```powershell
uv sync
```

也可通过 `pip install -r requirements.txt` 更新所用虚拟环境。新增 SQLGlot 用于 AST 解析；MySQL Connector/Python 至少为 9.2.0，以支持读写超时。本功能针对 MySQL 8.x；缺少只读事务或超时能力时拒绝继续查询，不降级为不受限制的执行。

在本地 `.env` 按需配置（不配置时使用以下默认值）：

```dotenv
MYSQL_ALLOWED_TABLES=drugs,inventory,sales_records
MYSQL_QUERY_TIMEOUT_SECONDS=10
MYSQL_MAX_ROWS=1000
```

白名单必须是逗号分隔的简单表名，不允许 `*` 或带库名的配置；设为空会拒绝执行。白名单需由可信维护者设置，不接受模型临时扩大权限。

## 查询边界

- 三个数据库工具统一受限；列表只展示白名单内实际存在的基础表，预览最多 100 行。
- SQLGlot 按 MySQL 方言解析单条 SELECT，允许只读 CTE、JOIN、子查询及 UNION；遍历作用域中的真实表，防止将非白名单表藏在别名、CTE 或子查询中。
- 禁止写操作、多语句、跨库访问、视图、导出文件、锁定读取、变量访问及赋值、SQL 注释和用户优化器提示。
- 仅批准的无副作用函数可用，未知函数和存储函数拒绝执行；`SLEEP`、`BENCHMARK`、`LOAD_FILE`、`GET_LOCK` 等不可用。函数集合见 `app/tools/sql_safety.py`。
- 实际执行重新生成的 SQL，不转发模型原文；固定 UTF-8 字符集和 `TRADITIONAL` SQL 模式，保证解析与执行的引号规则一致。
- 在专用连接内开启只读事务，禁用驱动多语句和本地文件导入。查询前核验基础表类型，不通过视图绕过白名单。
- 为外层结果施加上限，最多额外读取一行检测截断，按标准 CSV 转义输出。默认最多返回 1000 行，范围 1–10000。

工具层限制不替代数据库账号权限。部署时应给查询账号仅授予所需基础表的 SELECT 权限，不授予写入、FILE、EXECUTE 等权限；本次未自动创建用户或修改现有数据库授权。白名单不会隔离表内不同行，也不是字段级权限控制。

## 超时和重试语义

- 每条 SELECT 设置 MySQL 会话 `max_execution_time`，默认 10000 毫秒；同时设置锁等待上限。
- 连接超时最多 5 秒（不超过配置的查询秒数），驱动读写超时为查询上限加 2 秒。查询超时配置范围 1–300 秒。
- 只对超时、死锁、锁等待和部分临时连接故障重试。语法、认证、授权、表不存在、白名单及只读校验失败不自动重试。
- **最多重试 3 次**：连续失败时为首次执行加 3 次重试，共最多 4 次；退避分别为 0.25、0.5、1 秒。
- 同一次研搜任务的数据库工具共享 3 次重试预算。预算用完后再次出现需重试的错误，返回 `SQL_RETRY_EXHAUSTED` 并停止本任务后续数据库访问，模型换 SQL 或重新列出表名也无法重新获得预算；新提交的研搜任务重新开始。
- 脚本独立调用工具、没有 Agent 任务上下文时，每次调用拥有自己的最多 3 次重试预算。
- 此处限制的是单条语句和网络等待时间；含重试的整次工具调用可能超过单条查询上限，不是整个研究任务的总时限。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py'
```

测试覆盖写入/导出/锁/变量/危险函数、各层表引用、CTE 别名遮蔽、视图拒绝、配置失效、超时重试次数、任务预算共享、驱动参数及只读设置失败后禁止执行查询。真实本地 MySQL 另行验证了白名单列表、SELECT 和 1 秒服务器查询中断，详见当天开发日志。
