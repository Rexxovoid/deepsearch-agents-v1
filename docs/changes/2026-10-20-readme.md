# README 与当前项目结构同步

## 问题现象

README 保留了大量原项目教程章节、学习宣传和章节分支说明；结构树缺少账号、事件持久化、SQL 策略和队列模块，能力边界仍把已实现的登录、队列、持久化和回归测试列为缺失能力。前端启动命令和测试说明也存在重复或含义不准确的问题。

## 定位证据

核对实际文件清单，以及 `app/api/server.py` 路由、账号和事件存储位置、`app/task_queue.py` / `app/worker.py`、前端 package.json 和 Vite 配置、`.env.example`、现有持久化与队列说明后，确认 README 与代码现状不一致。

## 解决方法与具体修改位置

- `README.md`：以当前功能、执行流程、主要目录、PowerShell 启动步骤、配置、接口、数据存储和验证方式为主体重写；删除教程目录和学习宣传，将学习资料简要归属到原作者项目。
- 纠正能力边界：明确当前已支持账号归属控制、事件持久化和队列；刷新恢复与整项任务重试不同，尚未支持 Agent 中间步骤持久化恢复。
- 保留项目来源声明；不把个人知识文件夹列为公开仓库内容。
- `AGENTS.md`：记录后续功能修改需对关键逻辑、状态和边界添加简洁中文注释，解释用途及原因。

## 验证结果

按实际目录、路由、配置模板与现有实现核对文档；检查 README 本地文件链接、主要模块路径和 Markdown 代码围栏。此次仅文档修改，不运行应用测试，不将文档中的测试命令描述为本次已执行测试。

本次未重新验收外部模型、数据库、Tavily、RAGFlow 和浏览器交互；文档所列运行命令需结合部署环境配置。README 目录树为主要模块概览，不枚举每个文件。
